BEXELIZED PRODUCT CATALOG — QUICK START

1. Open index.html in your browser to preview the site.
2. The five category pages are:
   - index.html (Car Hanging)
   - bag.html
   - hanging.html
   - earrings.html
   - customized.html
3. All pages share css/style.css and js/app.js, so they keep the same design.
4. Add your product photos to assets/images/.
5. Open js/products.js and edit the sample products:
   - name: the product name shown below the photo
   - category: car-hanging, bag, hanging, earrings, customized
   - style: anime, cartoon, friendly, realistic
   - image: path to the image file
6. Copy the Instagram profile URL into the two links in each HTML page
   (search for https://www.instagram.com/).

No prices, quantities, cart, or checkout are included.
